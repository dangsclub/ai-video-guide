Blender 스크립트 예제

내장 Python API로 오브젝트, 타이틀, 렌더 설정을 빠르게 반복합니다.

실행 방법

  1. Blender에서 Scripting 작업 공간을 엽니다.
  2. Text Editor에서 New를 누르고 아래 예제 하나를 붙여 넣습니다.
  3. Run Script를 누르거나 마우스를 Text Editor 위에 두고 Alt+P를 누릅니다.
  4. 결과를 확인하고 자주 쓰는 코드는 .py 파일로 저장합니다.

스크립트는 현재 열려 있는 프로젝트를 변경합니다. 작업 전 .blend 파일을 저장하거나 사본에서 시험하세요.

예제 1. 선택 오브젝트 이름 일괄 변경

선택한 오브젝트를 Shot_01, Shot_02 형식으로 정리합니다.

import bpy

for index, obj in enumerate(bpy.context.selected_objects, start=1):
    obj.name = f"Shot_{index:02d}"
    obj.data.name = f"ShotData_{index:02d}" if obj.data else obj.name

예제 2. 3D 타이틀 오브젝트 만들기

현재 장면에 텍스트 오브젝트를 추가합니다. 내용과 위치를 장면에 맞게 바꿔 사용하세요.

import bpy

bpy.ops.object.text_add(location=(0, 0, 1))
title = bpy.context.object
title.name = "VideoTitle"
title.data.body = "AI VIDEO"
title.data.extrude = 0.025
title.data.size = 1.2

예제 3. 영상 렌더 설정

현재 장면의 해상도와 프레임 레이트, 출력 파일 경로를 설정합니다. 실제 렌더는 별도로 실행하세요.

import bpy

scene = bpy.context.scene
scene.render.resolution_x = 1920
scene.render.resolution_y = 1080
scene.render.resolution_percentage = 100
scene.render.fps = 30
scene.render.image_settings.file_format = "FFMPEG"
scene.render.ffmpeg.format = "MPEG4"
scene.render.filepath = "//renders/intro_"

//로 시작하는 경로는 현재 .blend 파일을 기준으로 한 상대 경로입니다. 장면을 이미지 시퀀스로 출력하면 렌더가 중단되어도 이어서 처리하기 쉽습니다.

예제 4. 선택 오브젝트에 키프레임 추가

현재 프레임에서 오브젝트 위치를 기록하고, 30프레임 뒤에 움직임을 기록합니다.

import bpy

obj = bpy.context.active_object
if obj is not None:
    scene = bpy.context.scene
    scene.frame_set(1)
    obj.location = (0, 0, 0)
    obj.keyframe_insert(data_path="location")

    scene.frame_set(31)
    obj.location = (2, 0, 0)
    obj.keyframe_insert(data_path="location")
