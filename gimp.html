GIMP 스크립트 예제

썸네일과 그래픽 작업을 Python 플러그인으로 반복 자동화합니다.

실행 준비

아래 예제는 GIMP 3.x Python 플러그인 기준입니다. GIMP 2.10의 Python-Fu는 실행 환경과 API가 다르므로 그대로 호환되지 않습니다.

  1. 아래 플러그인 틀을 video_guide.py로 저장합니다.
  2. GIMP의 환경 설정에서 플러그인 폴더를 확인하고 파일을 해당 폴더에 넣습니다. 필요하면 파일에 실행 권한을 부여합니다.
  3. GIMP를 다시 실행하고 이미지에서 Filters → Development → Video Guide를 선택합니다.
  4. 각 예제 코드를 틀 안의 run() 함수 본문에 넣어 한 번에 하나씩 실행합니다.
#!/usr/bin/env python3
import sys
from gi.repository import Gimp, GLib

class VideoGuidePlugin(Gimp.PlugIn):
    def do_query_procedures(self):
        return ["python-fu-video-guide"]

    def do_create_procedure(self, name):
        procedure = Gimp.ImageProcedure.new(
            self, name, Gimp.PDBProcType.PLUGIN, self.run, None
        )
        procedure.set_image_types("*")
        procedure.set_menu_label("Video Guide")
        procedure.add_menu_path("<Image>/Filters/Development")
        procedure.set_documentation(
            "Video Guide examples", "Small image workflow helpers", name
        )
        procedure.set_attribution("Video Guide", "Video Guide", "2026")
        return procedure

    def run(self, procedure, run_mode, image, drawables, config, run_data):
        # 예제 코드를 이 위치에 넣으세요.
        Gimp.message("Video Guide plugin is running")
        return procedure.new_return_values(Gimp.PDBStatusType.SUCCESS, GLib.Error())

Gimp.main(VideoGuidePlugin.__gtype__, sys.argv)

예제 1. 캔버스 크기 확인

현재 이미지의 가로·세로 픽셀을 확인합니다. 썸네일 비율이나 리사이즈 전 점검에 활용하세요.

width = image.get_width()
height = image.get_height()
Gimp.message(f"현재 캔버스: {width} x {height}px")

예제 2. 레이어 이름 일괄 정리

현재 이미지의 레이어 이름을 위에서부터 순서대로 지정합니다.

for index, layer in enumerate(image.get_layers(), start=1):
    layer.set_name(f"영상소스_{index:02d}")

Gimp.message("레이어 이름을 정리했습니다.")

예제 3. 이미지에 안내 메시지 표시

이미지를 열지 않았거나 레이어가 없는 상황을 점검할 때 사용할 수 있는 기본 가드입니다.

layers = image.get_layers()
if not layers:
    Gimp.message("먼저 작업할 레이어를 추가하세요.")
else:
    names = ", ".join(layer.get_name() for layer in layers)
    Gimp.message(f"레이어 {len(layers)}개: {names}")

원본에 바로 적용하기 전에 이미지 사본으로 테스트하세요. GIMP 3의 플러그인 API와 메뉴 위치는 업데이트에 따라 바뀔 수 있으니 설치한 버전의 문서를 확인하세요.
