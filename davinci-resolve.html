DaVinci Resolve 스크립트 예제

Resolve scripting API로 프로젝트와 미디어, 렌더 작업을 자동화합니다.

실행 준비

  1. Resolve에서 Preferences → System → General의 외부 스크립팅 접근을 허용합니다. 메뉴 이름은 버전에 따라 다를 수 있습니다.
  2. 설치 폴더의 Developer/Scripting 예제와 README를 확인하고, Python 환경에서 제공 모듈을 불러오도록 경로를 설정합니다.
  3. 아래 공통 연결 코드를 각 예제의 맨 위에 넣고, Resolve가 실행 중인 상태에서 Python으로 실행합니다.
import DaVinciResolveScript as dvr_script

resolve = dvr_script.scriptapp("Resolve")
if resolve is None:
    raise RuntimeError("DaVinci Resolve에 연결할 수 없습니다.")

project_manager = resolve.GetProjectManager()
project = project_manager.GetCurrentProject()
if project is None:
    raise RuntimeError("먼저 Resolve에서 프로젝트를 여세요.")

Resolve 버전·운영체제·에디션에 따라 API 설치 경로와 외부 접근 지원 범위가 다릅니다. 공식 설치 폴더의 API 문서 및 예제를 기준으로 설정하세요. 프로젝트 변경 스크립트는 사본에서 먼저 테스트하세요.

예제 1. 현재 프로젝트와 타임라인 확인

현재 프로젝트 이름과 열려 있는 타임라인을 출력합니다. 연결 상태를 시험할 때 유용합니다.

timeline = project.GetCurrentTimeline()
print("프로젝트:", project.GetName())
print("타임라인:", timeline.GetName() if timeline else "열린 타임라인 없음")

예제 2. 미디어 풀의 클립 목록 출력

프로젝트 루트 폴더에 등록된 클립의 이름과 길이를 확인합니다.

media_pool = project.GetMediaPool()
root_folder = media_pool.GetRootFolder()

for clip in root_folder.GetClipList():
    print(clip.GetName(), clip.GetClipProperty("Duration"))

예제 3. 선택한 클립을 타임라인에 추가

아래 목록을 프로젝트의 미디어 풀 클립으로 바꾼 뒤 실행합니다. 순서대로 현재 타임라인 끝에 추가됩니다.

media_pool = project.GetMediaPool()
root_folder = media_pool.GetRootFolder()
clips = root_folder.GetClipList()

if clips:
    result = media_pool.AppendToTimeline([clips[0]])
    print("타임라인 추가 결과:", result)
else:
    print("미디어 풀에 클립이 없습니다.")

예제 4. 렌더 작업 등록 및 시작

현재 타임라인을 MP4로 출력하도록 렌더 작업을 등록하고 시작합니다. 저장 경로를 컴퓨터에 맞게 수정하세요.

project.SetRenderSettings({
    "TargetDir": r"C:\Users\Public\Videos",
    "CustomName": "video_guide_export",
    "Format": "mp4",
    "VideoCodec": "H264"
})

job_id = project.AddRenderJob()
if job_id:
    project.StartRendering(job_id)
    print("렌더 작업 시작:", job_id)
else:
    print("렌더 작업을 등록하지 못했습니다. 출력 설정을 확인하세요.")

렌더 설정 키와 코덱 이름은 설치된 Resolve 버전과 시스템에서 달라질 수 있습니다. 작업을 시작하기 전에 Deliver 페이지의 출력 설정과 대상 경로를 확인하세요.
